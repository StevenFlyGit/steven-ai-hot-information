## 一、信息架构（IA）

```
AI 热点资讯平台
├─ 首页（精选流）────────── /items?mode=selected&window=24h
│   ├─ Hero 头条精选
│   ├─ 信息流卡片（标题/来源/时间/reason/分类标签）
│   └─ 右栏：热点榜 Top10 + 今日日报入口
├─ 热点榜 ──────────────── /hot-topics（Top10, rank 排序）
│   └─ 含 links.story → 事件详情
├─ 事件详情 ────────────── /stories/{publicId}
│   ├─ AI 综述 digest（演化更新）
│   ├─ 逆序报道时间线
│   └─ 最新进展 latest + 相关资讯
├─ 日报归档 ────────────── /dailies（索引）+ /dailies/{date}
└─ 检索中心 ────────────── /items 组合（q + category + window + by + 本地来源）
    ├─ 关键词(直接API) · 分类(直接API) · 时间(直接API)
    ├─ 来源(客户端派生) · 智能聚合(策展+AI综述)
    └─ 空态：selected 空 → 自动回退 all 并标注
```

## 二、三版本选择建议

| 目标 | 推荐 |
|------|------|
| 个人 demo、求"眼前一亮"、科技受众 | **A 暗黑霓虹** |
| 内容品牌、长文阅读、高端调性 | **B 杂志编辑** |
| 从业者"一眼掌握全局"、信息密度 | **C 数据仪表盘** |

## 三、关键工程提示（与产品形态强相关）

结合前期讨论，平台落地时三种形态逻辑不同，**接入层要分开规划**：

1. **H5 / 小程序**：浏览器/微信沙箱通常**不能直连** `aihot.virxact.com`（CORS / 微信 request 合法域名白名单）。必须有一层**极薄后端代理**：页面 → 你的后端 → AIHOT → 回传。小程序还需在微信后台把域名加白名单、过审核。
2. **桌面（Electron/Tauri）**：后端即本地进程，无 CORS 限制，可直接服务端请求，还能做系统托盘后台刷新、本地缓存、通知——与"调接口"最顺滑。
3. **实时拉取 vs 定时缓存**：
   - 实时 = 每次加载/刷新调一次接口；配合 skill 的 `ETag / If-None-Match`，内容没变返回 `304` 直接复用，不必重复处理。
   - 定时缓存 = 后端每 5–15 分钟拉一次存入自有库，前端读缓存；资讯无秒级新鲜度，更省、更快、可离线。
   - **建议**：demo 用实时 + ETag；真做平台切定时缓存（或 ETag 短 TTL 混合）。
