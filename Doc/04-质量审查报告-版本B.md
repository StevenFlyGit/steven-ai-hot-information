## 三、Anti-Slop 门控（逐条核对 02 文档 8 条纪律 + 三条铁律）

### 三条铁律

| 铁律 | 核对结果 | 证据 |
|------|----------|------|
| ① 彩色 ≤ 3（navy+orange+olive） | ⚠️ 基本符合，存 1 处张力 | 主色 navy/orange/olive 三色，无彩虹/渐变。但 `.tag.local`、智能警示文字复用 `--danger(#B5553A)` —— 02 文档将其定义为「由橙降饱和派生、仅文字提示」，属同色系派生，技术上计入「橙系」而非新色相；视觉上把彩色观感推到 4 种，与「≤3」铁律存在表述张力（见 P2）。 |
| ② 禁渐变 / 发光 / 霓虹 | ✅ 通过 | 全文件无 `linear/radial-gradient`、无 `text-shadow`、无大模糊 `box-shadow`；仅 `--shadow-card:0 1px 2px rgba(27,42,74,.04)` 极轻描边阴影、`.tl-item::before` 的 `0 0 0 1px var(--line)` 1px 描边环（非发光）；sticky 导航 `rgba(251,250,247,.9)` 半透明无 blur 光晕。 |
| ③ 分类 chip 描边（不填色块） | ✅ 通过 | `.chip`/`.qchip` 均为 `1px --line` 描边 + `--ink-700`；选中态 `background:--navy;color:#fff`（02 文档 3.4/3.6 指定之选中态，非高饱和色块）。无红/绿交通灯，状态仅用单色点（orange=进行中 `.event-badge .dot`，ink-500=归档）。 |

### 8 条 Anti-Slop 纪律

| # | 纪律 | 结果 | 命中/违反项与证据 |
|---|------|------|------------------|
| 1 | 字体不超两套（衬线+无衬线） | ❌ **违反** | **`.apibox .acode`** 使用 `font-family:"SF Mono",ui-monospace,"Cascadia Code",Consolas,monospace;` —— 引入**第三套等宽字体**，直接违反「字体不超两套」。 |
| 2 | 彩色 ≤3；禁彩虹渐变/外发光/玻璃拟态/**等宽终端元素** | ❌ **违反**（等宽终端） | 同上，`.apibox` 的等宽代码框即典型「C 版等宽数据终端元素」，为 02 文档明文禁止的雷区。颜色上限本身通过（见铁律①）。 |
| 3 | 标签不填色块；状态用单色点 | ✅ 通过 | chips 描边；状态点 orange/ink-500。无红绿。 |
| 4 | 留白节奏统一（8px 栅格，宁稀勿挤） | ✅ 通过 | `--pad:clamp(20px,4vw,40px)`、区块上距 46–56px、卡间距以 hairline 分隔；无小报式密集。 |
| 5 | 衬线职责分明（仅标题/刊期/序号/引文；长文无衬线） | ✅ 通过 | 衬线仅用于 h1–h4、品牌字、序号（`.mini-hot`/`.hot-rank`/`.card .score`/`.daily-index .di-date`/`.dc-flash .idx`）、引文标识；digest/摘要/推荐理由/日报正文均无衬线（sans）。无衬线长文降可读性风险。 |
| 6 | 禁假数据占位（可信中文 AI 资讯，标「仅 UI」） | ⚠️ 基本符合，1 处风险 | 内容均为可信中文 AI 资讯（GPT-5.2/Gemini3/Llama4 等），原型角标与页脚标注「仅 UI，不含后端逻辑」「署名≠授权」。但**精选流卡片「评分 98/92/88…」**为带精确数值的字段，来源不明、不在数据模型内，有「编造统计/热度值」观感（见 P1）。 |
| 7 | 分隔克制（仅 1px 暖灰 hairline；禁多重装饰线/阴影堆叠） | ✅ 通过 | 全站分隔仅 `--line`(1px) / `--line-strong`；橙 tick（`.seclabel::before` 30×2px、`.tl-title::before` 24×2px）为克制编辑点缀；阴影仅极轻 `--shadow-card` 用于 filterbar/daily 卡片。无拟物/堆叠。 |
| 8 | 数据诚实（来源标「本地过滤」、智能标「非语义检索」、不杜撰热度） | ❌ **局部违反** | 来源与智能标注**完全准确**：检索中心④「本地过滤 · 客户端派生」+ 说明「skill 未暴露独立来源参数…按 source.name 过滤」；⑤「智能聚合层 · 非语义检索」+ 警示「skill 无向量语义搜索端点，此非字面语义检索」；apibox note 如实区分 API 参数 / 本地过滤 / 智能聚合；首页「编辑手记」亦重申。热点榜诚实用「—」而非杜撰热度（✅ 优秀）。 **但**精选流卡片（`.card .score`「评分 98」等）擅自呈现精确数值分，既非 AIHOT 文档字段、也不在 02 卡片规范（3.2 仅 来源·北京时间·window），与「不杜撰热度值」精神及热点榜的诚实立场矛盾。 |

## 五、问题清单与修正建议（优先级返回 prototype-builder）

### P0（必须修复 · 阻断发布）
**无。** 无渐变/发光、无破损布局、无对比度硬失败、无编造证言级假数据、无 emoji 替代图标、无等宽 AI 卡片套路、响应式完备。

### P1（建议修复 · 影响品质，须处理）

**P1-1 · 精选流卡片「评分 98/92/88…」越界（纪律 #8 + 02 卡片规范 3.2 缺失该字段）**
- 位置：`.card .meta` 末位 `<span class="score">评分 98</span>`（6 张卡片均有，含 `margin-left:auto` 右对齐）。
- 问题：该字段非 AIHOT 文档字段，不在 02 文档 3.2 卡片规范（仅 来源·北京时间·window），且与热点榜诚实用「—」的立场直接矛盾，呈现精确数值分有「杜撰热度/质量值」观感。
- **修复建议**：删除 `.card .score` 元素及其 CSS（`.card .score{...}` 整段）。若产品确需编辑权重维度，改为明确的「编辑权重」文案并注明「策展主观分，非平台热度」，或彻底回归 02 规范只保留 来源·北京时间·window 元信息行。优先级：**高**。

**P1-2 · 检索中心 API 示意框使用等宽字体（纪律 #1/#2 违反）**
- 位置：`.apibox .acode{font-family:"SF Mono",ui-monospace,"Cascadia Code",Consolas,monospace;}`。
- 问题：引入第三套字体 + C 版等宽终端元素，违反「字体不超两套」「禁等宽终端元素」铁律。
- **修复建议**：将 `.apibox .acode` 字体改为 `var(--font-sans)`（已用 `.verb` 橙、`--param` navy、`--key` olive 做语义着色，足够区分）；或将 `.apibox` 整体重构为「技术注」编辑风 inset（去代码框感、去等宽）。保留 GET/参数着色即可。优先级：**高**。

**P1-3 · 关键元信息对比度不达标（02 文档 2.1 对比度纪律 + WCAG AA）**
- 位置：`.card .meta .muted`（北京时间/window）、`.lede .byline .muted`、`.hot-sub .muted`、`.event .event-meta .muted`、`.daily-card .dc-meta .muted`、`.timeline .when` 等，均 `color:var(--ink-500)`。
- 问题：`--ink-500(#8A8F98)` 在 `#FBFAF7` 上对比度约 **3.1:1**，低于 WCAG AA 对正常文字的 **4.5:1**；且 02 文档 2.1 明确「ink-500 不可用于小号关键文本」「正文性元信息一律用 ink-700」。上述均为 12.5–13px 的**关键 meta（时间/窗口）**，属误用。
- **修复建议**：将关键 meta 的 `.muted` 统一改为 `var(--ink-700)`（≈7.4:1，满足 AA+）；仅保留 `--ink-500` 用于真正的装饰性 ≥18px 文本（如 `.side .side-sub`、页脚）。可新增 `.meta .key{color:var(--ink-700)}` 替换现有 muted 关键项。优先级：**中高**（无障碍 + 纪律）。

### P2（可选优化 · 锦上添花）

**P2-1 · `--danger` 第四色收口**
- 位置：`.fb-label .tag.local`、`.smart-row .txt b` 警示、`.apibox .note .local` 用 `--danger(#B5553A)`。
- 建议：虽为橙系派生且在 02 令牌内，但视觉上把彩色推到 4 种。可统一回 `--orange` 文字 + 描边表达「本地过滤」警示；或请 design-system-expert 在 02 文档中明确「danger 为橙系派生、不计入彩色上限 3」，以免后续评审歧义。优先级：**低**。

**P2-2 · 焦点态与 reduced-motion 降级**
- 位置：`.gsearch input`/`.fb-search input` 设 `outline:none` 后无可见 focus 指示；`.view`/`.daily-card` 的 `fade` 动画无 `prefers-reduced-motion` 降级。
- 建议：下划线输入框 focus 加 `border-bottom-color:var(--orange)` 或 `outline:2px solid var(--navy);outline-offset:2px` 可见态；补 `@media (prefers-reduced-motion: reduce){*{animation:none!important;transition:none!important}}`。优先级：**低**。
