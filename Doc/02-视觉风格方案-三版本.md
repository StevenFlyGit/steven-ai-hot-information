# AI 热点资讯平台 · 视觉风格方案（三版本）

> 文档版本：v1.0 · 产出阶段：Phase 2 设计系统
> 用途：为三个候选视觉方向生成定制化设计令牌，供用户选择后进入原型细化。
> 适用：浅色 IDE 主题下的预览，所有原型均保证对比度与可读性。

---

## 版本 A · 科技暗黑霓虹（Dark Neon）

**定位**：最"眼前一亮"，科技感强，适合年轻科技受众与夜间浏览。

| 令牌 | 值 |
|------|----|
| 背景底 | `#0A0E1A`（近黑蓝） / 卡片 `#121829` |
| 主强调色 | 霓虹青 `#22D3EE` → 紫 `#A855F7` 渐变 |
| 辅助色 | 品红 `#F472B6`、荧光绿 `#34D399` |
| 文字 | 主 `#E6EAF5`、次 `#94A3C4`、弱化 `#5B6788` |
| 字体 | 标题 `Sora / Space Grotesk`；正文 `Inter`；中文 `PingFang SC / Microsoft YaHei` |
| 圆角 | 16–20px（大圆角玻璃卡） |
| 阴影/光晕 | 卡片外发光 `0 0 0 1px rgba(34,211,238,.25), 0 8px 40px rgba(34,211,238,.12)` |
| 组件特征 | 玻璃拟态（backdrop-blur）、渐变描边按钮、发光标签、网格噪点背景 |

**氛围关键词**：未来感、流光、深邃、能量感。

---

## 版本 B · 清爽杂志编辑风（Light Editorial）

**定位**：阅读舒适、显高端，适合长文与"每日必读"心智，类 Stripe Press / Apple News。

| 令牌 | 值 |
|------|----|
| 背景底 | `#FBFAF7`（暖白）/ 卡片 `#FFFFFF` |
| 主强调色 | 墨蓝 `#1B2A4A`、点缀橙 `#E0653A` |
| 辅助色 | 橄榄 `#6B7A4F`、灰 `#8A8F98` |
| 文字 | 主 `#1A1A1A`、次 `#54534E`、弱化 `#8A8F98` |
| 字体 | 标题衬线 `Noto Serif SC / Source Han Serif`；正文 `Noto Sans SC / Inter` |
| 圆角 | 8–12px（克制小圆角） |
| 分隔 | 1px 细线 `#EAE6DF`、大量留白 |
| 组件特征 | 大字号衬线标题、首字下沉、栏目分隔线、克制的单色标签 |

**氛围关键词**：克制、编辑品味、可信、纸张质感。

---

## 版本 C · 数据仪表盘风（Data Dashboard）

**定位**：信息密度高、专业高效，适合"一眼掌握全局"，类 AI 版 Bloomberg / 行情终端。

| 令牌 | 值 |
|------|----|
| 背景底 | `#0F1419`（深 slate）/ 面板 `#161D26` |
| 主强调色 | 琥珀 `#F5A623`、科技蓝 `#3B82F6` |
| 辅助色 | 红 `#EF4444`（跌/预警）、绿 `#22C55E`（涨/热点） |
| 文字 | 主 `#E8EDF2`、次 `#9AA7B4`、数据高亮 `#F5A623` |
| 字体 | 等宽数据 `JetBrains Mono`；UI `Inter`；中文 `PingFang SC` |
| 圆角 | 6–10px（紧凑） |
| 布局 | 卡片网格、左侧导航 rail、顶部 KPI 条 |
| 组件特征 | 排名徽标、迷你 sparkline、状态点、密度优先 |

**氛围关键词**：高效、专业、信息密度、终端感。

---

## 三版本速览对比

| 维度 | A 暗黑霓虹 | B 杂志编辑 | C 数据仪表盘 |
|------|-----------|-----------|-------------|
| 第一眼记忆点 | ★★★★★ | ★★★☆ | ★★★★ |
| 阅读舒适度 | ★★★ | ★★★★★ | ★★★ |
| 信息密度 | ★★★★ | ★★☆ | ★★★★★ |
| 商业化质感 | 科技品牌 | 媒体/内容品牌 | 金融/数据品牌 |
| 适配场景 | 科技社区/夜间 | 每日必读/长文 | 从业者盯盘式 |

> 推荐：个人 demo 求"眼前一亮"→ **版本 A**；若偏内容品牌调性 → **版本 B**；若强调"全局掌握"→ **版本 C**。原型文件见 `prototype-A/B/C-*.html`。
