# AI 热点资讯平台 · 设计需求摘要（权威版 v2.0）

> 本文档由 **discovery-analyst（许明需）** 作为「设计原型专家团」成员独立产出，是团队当前阶段（Phase 1 需求发现）的权威需求文档，覆盖并取代此前草稿版。
> 所有功能以 AIHOT skill（aihot.virxact.com 匿名只读 v1 API）透出的真实能力为唯一事实来源；视觉方向已锁定 **版本 B · 杂志编辑风**。
> 配套：`01-产品方案总览.md`、`02-视觉风格方案-三版本.md`、`prototype-B-杂志编辑风.html`。

## 一、设计五要素（Design Brief）

| 要素 | 结论 |
|------|------|
| **场景 Surface** | Web 端「AI 热点资讯查看 / 搜索 / 抓取」平台（个人 demo 阶段，H5 优先，后续可扩展桌面端）；本次聚焦高保真视觉原型，不实现后端逻辑 |
| **受众 Audience** | 关注 AI 动态的从业者、研究者、产品经理、投资人、科技爱好者；核心诉求是"快速看懂今天 AI 圈发生了什么"，审美预期偏高、偏好可信赖的媒体/内容品牌质感 |
| **调性 Tone** | **版本 B · 杂志编辑风**：浅色、衬线大标题、大留白、高端阅读感、克制配色；第一眼"眼前一亮"靠编辑品味而非视觉炫技（区别于 A 的霓虹冲击 / C 的密度冲击） |
| **品牌上下文 Brand** | 无既有品牌资产；蓝本为 AIHOT 中文 AI 资讯服务。数据来源须署名 AIHOT、保留原文跳转；商业用途需取得书面授权（署名 ≠ 授权） |
| **规模 Scale** | 单应用、多页面（首页精选流 / 热点榜 / 事件详情 / 日报归档 / 检索中心）；静态高保真原型，含必要的客户端筛选与交互态，无服务端实现 |

## 二、功能架构（基于 skill 真实能力映射）

平台划分为 5 个核心模块，全部由 AIHOT v1 接口驱动：

| 模块 | 对应接口 | 说明 |
|------|----------|------|
| 精选资讯流（首页） | `GET /api/v1/items?mode=selected&window=24h\|7d` | 编辑精选池，高门槛策展 |
| 热点榜 | `GET /api/v1/hot-topics` | 当前热点 Top10，按 rank 排序，部分含 `links.story` 事件入口 |
| 事件详情 | `GET /api/v1/stories/{publicId}` | 逆序报道时间线 + AI 综述(digest，随事件演化更新) + 最新进展(latest) |
| 日报归档 | `GET /api/v1/dailies?limit=N` + `/api/v1/dailies/{YYYY-MM-DD}` | 固定日切成品，非滚动时间窗 |
| 检索中心 | `GET /api/v1/items`（组合 `q/category/window/by`） | 关键词 + 分类 + 时间 + 来源(本地) + 智能聚合 |

**全局合规 / 优化约束（须落地为产品设计规则）：**
- 接口均为匿名只读 GET，无需 API Key；反复查同 URL 用 `ETag / If-None-Match`，`304` 复用；定时轮询同端点 ≥ 60s。
- 资讯无秒级新鲜度 → 前端可做短 TTL 缓存，不必每次刷新硬拉。
- 个人非商业 / 公益 / 组织内部免费；任何对外商业产品、收费、数据转售、公开镜像、白标、批量再分发，均须取得 AIHOT 书面授权。
- 页面须保留「数据来源：AIHOT」署名与原文跳转（`links.original`）以便核对。

## 三、搜索 / 筛选能力映射表（5 项，诚实标注来源）

| # | 能力 | 映射到的真实能力 | 类型 | 备注 |
|---|------|------------------|------|------|
| 1 | **关键词搜索** | `q=<关键词>` 参数（items 接口） | **直接 API 能力** | skill 原生支持；精选池命中为空时回退 `mode=all` 并标注"未进入精选" |
| 2 | **分类筛选** | `category=<slug>`：模型 / 产品 / 论文 / 行业 / 技巧 | **直接 API 能力** | 5 个固定 slug，做成筛选 chips |
| 3 | **时间范围筛选** | `window=24h\|7d` + `by=timeline\|published` | **直接 API 能力** | `timeline`=AIHOT 时间轴(默认)；`published`=第三方原文发布时间 |
| 4 | **来源筛选** | 返回字段 `source.name` | **客户端派生 / 本地过滤** | ⚠️ skill 未暴露独立来源参数，只能拉取后在结果集上做客户端过滤；UI 须诚实标注"本地过滤" |
| 5 | **智能 / 语义检索** | `hot-topics` 编辑智能 + `stories` 的 AI 综述(digest) + `selected` 精选策展 + `reason` 推荐理由 | **智能聚合层（非语义搜索）** | ⚠️ skill 没有向量语义搜索端点；"智能"= 编辑策展 + AI 综述聚合 + 推荐理由，而非字面语义检索。建议呈现为"智能追问 / 事件脉络 / 编辑精选"能力 |

> **诚实声明**：第 4、5 项并非 skill 直接提供的独立检索端点，而是基于返回数据的客户端能力或策展 / 聚合能力。若未来要做真正的语义检索，需自建向量库或申请 AIHOT 高级能力，超出当前 skill 范围。原型与文档中不得标注为"语义搜索（向量）"。

## 四、页面结构（核心页面 + 区块）

1. **首页（精选流） `/items?mode=selected&window=24h`**
   - 顶栏：品牌署名 + 主导航（精选 / 热点榜 / 日报 / 检索）+ 全局搜索框
   - Hero：当日头条精选（大字号衬线标题卡）
   - 信息流：卡片列表（标题、来源、北京时间、推荐理由 `reason`、分类标签）
   - 右栏：实时热点榜 Top10 + 今日日报入口
2. **热点榜页 `/hot-topics`**
   - 排名列表（名次、标题、rank，含 `links.story` 可进事件详情）
   - 不展示 / 推算内部热度值，只用 rank 顺序
3. **事件详情页 `/stories/{publicId}`**
   - 标题 + 来源 + AI 综述 digest（随事件演化更新）+ 最新进展 latest
   - 逆序报道时间线(timeline) + 相关资讯 + 一键跳原文 `links.original`
4. **日报归档页 `/dailies` + `/dailies/{date}`**
   - 日期索引列表 + 单日报（sections / flashes）+ 原文跳转
5. **检索中心页 `/items` 组合**
   - 组合筛选器：关键词输入 + 分类 chips + 时间窗 + 来源下拉（本地）+ 智能聚合开关
   - 结果流 + 空态说明（精选空 → 自动回退 `all` 并灰色标注"未进入精选"）

## 五、核心交互流程（关键用户旅程）

**旅程 1 · 浏览今日精选**：首页精选流 → 点开卡片看详情（`links.aihot` 主链接）→ 顺带看"相关事件"时间线。

**旅程 2 · 组合检索**：检索中心输入"Agent" + 选分类「产品」+ 时间「7 天」+ 来源本地过滤 → 看结果；精选池空时自动回退 `mode=all` 并标注"未进入精选"。

**旅程 3 · 追热点脉络**：热点榜点第 3 名（含 `links.story`）→ 事件详情看 AI 综述 + 逆序时间线 + 最新进展 → 一键跳原文 `links.original`。

**旅程 4 · 读日报**：日报归档选指定日期 → 看当日策展 + 跳原文核对。

## 六、视觉调性 · 锁定「版本 B 杂志编辑风」

**决策锁定**：本次原型细化统一采用 **版本 B（Light Editorial / 杂志编辑风）**，不再提供 A / C 候选。理由——用户已明确选定；该方向契合"每日必读 / 高端阅读感"心智，且以编辑品味达成"眼前一亮"，审美风险最低、最显可信赖。

**落地设计令牌（供原型构建师直接使用）：**

| 令牌 | 值 |
|------|----|
| 背景底 | `#FBFAF7`（暖白）/ 卡片 `#FFFFFF` |
| 主强调色 | 墨蓝 `#1B2A4A`、点缀橙 `#E0653A` |
| 辅助色 | 橄榄 `#6B7A4F`、灰 `#8A8F98` |
| 文字 | 主 `#1A1A1A`、次 `#54534E`、弱化 `#8A8F98` |
| 字体 | 标题衬线 `Noto Serif SC / Source Han Serif`；正文 `Noto Sans SC / Inter` |
| 圆角 | 8–12px（克制小圆角） |
| 分隔 | 1px 细线 `#EAE6DF`、大量留白 |
| 组件特征 | 大字号衬线标题、首字下沉、栏目分隔线、克制的单色标签 |

**落地要点（六条硬约束）：**
1. **浅色背景**：以暖白 `#FBFAF7` 为底，卡片纯白，拒绝任何深色 / 霓虹底。
2. **衬线标题**：所有层级标题使用衬线字体（Noto Serif SC），正文用无衬线，形成"杂志感"层级对比。
3. **大留白**：区块间距、行距、左右页边距显著放大；一屏信息量克制，宁稀勿挤。
4. **阅读优先**：资讯流以"可读的长卡片"为主，突出标题 + 推荐理由 `reason` + 来源，弱化按钮与装饰。
5. **克制配色**：强调色仅墨蓝 + 点缀橙两点，全站不超过 3 个彩色，分类标签用单色描边而非填色块。
6. **Editorial 排版**：引入栏目分隔线、首字下沉、署名行、刊期感日期；热点榜用"第 N 名"序号排印而非排行榜特效。

**Anti-Slop 提示（版本 B 专项）**：避免把杂志风做成"密集小报"——留白不足、衬线滥用、装饰线过多均判为 Slop；分类标签不得用高饱和色块；全站不得出现 A 的发光 / 玻璃拟态或 C 的等宽数据终端元素。
