# AI 热点资讯平台 · 视觉风格方案（版本 B · 杂志编辑风）— 权威设计系统

> **本文档由 design-system-expert（彩格调）作为「设计原型专家团」成员产出。**
> 本文档取代 `02-视觉风格方案-三版本.md` 中的 B 部分，作为版本 B 的**唯一权威来源**，供原型构建师（筑原型）直接落地高保真页面。
> 视觉方向已锁定：**版本 B · 杂志编辑风（Light Editorial）**。需求与功能约束以 `00-设计需求摘要.md` 为准，本文件不重复功能定义，只沉淀可执行的视觉令牌与组件规范。

## 一、基底系统选型（Base System Selection）

**选定基底：`Warm Editorial`（通用起始类 · 编辑阅读风）**

选型理由：本项目是「浅色暖白 + 衬线大标题 + 大留白 + 克制墨蓝/点缀橙」的中文 AI 资讯阅读平台，`Warm Editorial` 是 71 套系统中唯一以"暖色纸张质感 + 编辑阅读优先 + 双字体层级对比"为内核的基底，与版本 B 心智完全同构；相较媒体类的 `Wired` / `The Verge`（偏冷感科技新闻、强对比网格）或 `Apple`（偏产品展示而非长文阅读），`Warm Editorial` 更贴合"每日必读 / 高端阅读感"的调性，且天然约束了彩色数量，规避了霓虹与终端风雷区。

基底只提供"骨架与纪律"，下面所有令牌为**针对本项目定制**，非简单套用。

## 二、设计令牌（Design Tokens）

### 2.1 色彩系统（Color · HEX + CSS 变量）

| 令牌 | 变量 | HEX | 用法说明 |
|------|------|-----|----------|
| 页面背景 | `--bg` | `#FBFAF7` | 暖白纸感底，全站唯一背景；禁止深色/霓虹底 |
| 卡片/面板 | `--surface` | `#FFFFFF` | 纯白卡面，与暖白底形成微弱层次 |
| 凹陷底纹 | `--surface-sunken` | `#F6F3EC` | AI 综述 digest、引文块等低调底色，非独立色相 |
| 主文字 | `--ink-900` | `#1A1A1A` | 标题、正文主色；与 `--bg` 对比 ≈14:1（AAA） |
| 次文字 | `--ink-700` | `#54534E` | 正文补充、来源/时间等**关键元信息**；对比 ≈7.6:1（AA+） |
| 弱化文字 | `--ink-500` | `#8A8F98` | 仅用于 ≥18px 装饰性元信息、图标；对比 ≈3.2:1，**不可用于小号关键文本** |
| 墨蓝（主强调） | `--navy` | `#1B2A4A` | 品牌字、链接、激活态、序号；对比 ≈14:1；全站第一强调色 |
| 点缀橙（强调） | `--orange` | `#E0653A` | 激活下划线、标记点、kicker、"进行中"状态；仅作重点笔触，不铺面 |
| 橄榄（第三低饱和色） | `--olive` | `#6B7A4F` | 仅用于分类 kicker / 低强调标签；全站第三且唯一低饱和彩色 |
| 分隔线 | `--line` | `#EAE6DF` | 1px 暖灰 hairline，全站唯一分隔语言 |
| 强分隔线 | `--line-strong` | `#DDD8CE` | 仅用于刊头/页脚等结构性重线 |
| 危险/警示（同色系） | `--danger` | `#B5553A` | 由橙降饱和派生，仅文字提示；禁止引入红/绿交通灯 |

**色彩纪律**：全站彩色 ≤ 3（navy、orange、olive 低饱和）；状态不靠红绿，用单色点 + 文字（进行中=orange 点，归档=ink-500 点）。
**对比度复核**：`--ink-900`/`--navy`/`--ink-700` 均达 AA+；`--orange` 仅用于大字号/标记/下划线（≥3:1 满足）；`--ink-500` 仅装饰，正文性元信息一律用 `--ink-700`。

### 2.2 排版系统（Typography）

**字体栈（全站仅 2 套）**
- 衬线（标题/刊期/序号）：`--font-serif: "Noto Serif SC", "Source Han Serif SC", "Songti SC", Georgia, serif;`
- 无衬线（正文/元信息/UI）：`--font-sans: "Noto Sans SC", "Inter", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;`

**字号阶梯（Type Scale）**

| 级别 | 用途 | 字号 | 行高 | 字重 | 字间距 | 字体 |
|------|------|------|------|------|--------|------|
| H1 | Hero 头条 | `clamp(32px, 4.2vw, 44px)` | 1.25 | 800 | -0.01em | serif |
| H2 | 事件/详情标题 | `clamp(26px, 3vw, 30px)` | 1.3 | 700 | -0.01em | serif |
| H3 | 资讯卡标题 | `22px` | 1.35 | 700 | 0 | serif |
| H4 | 栏目标题/侧栏 | `17px` | 1.4 | 700 | 0 | serif |
| Body | 正文/综述 | `16–17px` | 1.7 | 400 | 0 | sans |
| Caption | 元信息/来源时间 | `12.5–13px` | 1.5 | 400 | 0 | sans（用 ink-700） |
| Kicker | 栏目标签/眉题 | `12px` | 1.4 | 700 | 0.12em | sans（olive，大写拉丁） |

**排印纪律**：衬线只服务标题、刊期、序号、引文；正文与元信息一律无衬线。Kicker 拉丁部分 `text-transform: uppercase` + 字间距 0.12em；中文眉题不加 uppercase。首字下沉仅用于 Hero 头条首段（可选，1 字，serif，orange 或 navy）。

### 2.3 间距与栅格（Spacing & Grid）

- **基础单位**：8px。节奏阶梯 `4 / 8 / 12 / 16 / 24 / 32 / 40 / 56 / 72 / 96 px`。
- **容器最大宽**：`--maxw: 1120px`（对齐原型 `.wrap`）；长文阅读列（事件综述）内收至 `720px` 提升可读性。
- **页边距**：`clamp(20px, 4vw, 40px)`（移动端 ≥20px）。
- **栅格**：首页双栏 `1.7fr : 1fr`（gap 36px）；Hero `1.5fr : 1fr`（gap 40px）；侧栏热点榜以 1px 左边线分隔，左内距 28px。
- **区块垂直节奏**：栏目标签上间距 46–56px；卡间距 22px（以 hairline 分隔，非外边距堆叠）；宁稀勿挤。

### 2.4 圆角与阴影（Radius & Elevation）

- **圆角**：`--r-sm: 8px`（按钮/标签/面板）、`--r-md: 12px`（筛选栏/事件卡）、`--r-pill: 999px`（chips）。
- **阴影纪律（克制）**：默认**用 1px `--line` 描边替代阴影**；仅允许极轻量阴影 `--shadow-card: 0 1px 2px rgba(27,42,74,0.04)`。Hover 态：边框转 `--navy` + 同款轻阴影，**禁止**外发光、玻璃拟态模糊（sticky 导航如需半透明，透明度 ≤0.9 且不加 blur 光晕）、禁止拟物厚阴影。

### 2.5 Z-index 与层级

`nav (sticky)=30` · `proto 角标=50` · `下拉/弹层=60`。层级仅靠 hairline 与底色区分，不靠投影堆叠。

## 三、组件规范（Component Specs）

> 每个组件给出"关键视觉规则"，原型构建师据此落地；状态/交互以 `00-设计需求摘要.md` 的功能映射为准。

### 3.1 顶部导航（Top Nav）
- sticky 吸顶，`border-bottom: 1px --line`；底为 `--bg`（半透明 ≤0.9，无 blur 光晕）。
- 品牌字 `AI·HOT 资讯`：serif 800，`--navy`，"HOT" 用 `--orange` 强调。
- 主导航（精选/热点榜/日报/检索）：无框文字链接，`--ink-700`；激活态 `color:--navy` + `border-bottom: 2px --orange`。
- 全局搜索：下划线输入框（`border-bottom:1px --navy`），无填充盒；placeholder `--ink-500`。

### 3.2 资讯卡片（News Card）
- **无卡盒**，以 `border-top/bottom: 1px --line` 分隔；首卡加顶线，末卡留白收尾。
- 结构：kicker（olive 分类，大写）→ H3 serif 标题 → 元信息行（来源 · 北京时间 · window，用 `--ink-700`）→ 推荐理由 `reason`（italic `--ink-700`，首尾加 orange 引号「" "」）。
- Hover：标题转 `--navy`；不做底色翻转、不做阴影弹起。
- 主链接走 `links.aihot`；原文跳转走 `links.original`（footer/元信息内标注"数据来源：AIHOT"）。

### 3.3 热点榜条目（Hot List Item）
- 以"**第 N 名**"序号排印（serif counter，numeral 用 `--orange`，字号 16px，min-width 20px），**禁止**排行榜进度条/热度柱/火花特效。
- 条目：标题（`--ink`）+ 副行来源（`--ink-500`，≥18px 或装饰性）；`border-bottom:1px --line`。
- 含 `links.story` 的条目，副行补"（含事件脉络）"文字链接，跳转事件详情；不推算、不展示内部热度值。

### 3.4 筛选 / 搜索栏（Filter & Search Bar）
- 外层 `border:1px --line` + `--r-md` + `--surface` 面板；内边距 20–22px。
- 关键词：下划线输入（`border-bottom:1px --navy`），无填充盒。
- 分类 chips：outline pill（`1px --line`，`--ink-700`），选中态 `background:--navy; color:#fff`（**禁填高饱和色块**）。
- 时间窗 `window`：分段控件（outline，`24h/7d`），选中 navy 填充。
- 来源下拉：标注"（本地过滤）"，诚实声明为客户端派生（非 API 参数）。
- 智能聚合开关：toggle，knob 用 `--orange`；文案标注"编辑策展 + AI 综述，非语义检索"。

### 3.5 事件详情页区块（Event Detail）
- 容器：`border:1px --line` + `--r-md` + `--surface`，内边距 30px。
- 状态徽标：olive 文字 + orange 圆点（"● 事件进行中 · 含 AI 综述"）；归档态用 ink-500 点。
- 标题 H2 serif；AI 综述 digest：`--surface-sunken` 底 + `border-left:3px --orange`，内文 `--ink-700`，"AI 综述："用 `--navy` 加粗。
- 时间线：左侧 `2px --line` 竖线 + orange 圆点节点（白边 + 1px `--line` 描边）；节点文字 when（ink-500）/ what（ink）。
- 最新进展 latest：orange italic + `border-left:3px --orange`。
- 一键跳原文：`links.original` 文字链接（orange 下划线）。

### 3.6 标签 / 分类 Chip（Tag / Category）
- 统一 outline pill：`1px --line`，`--ink-700`，`--r-pill`；选中 navy 填充白字。
- **禁止**彩色填色块、渐变描边、发光；分类色彩仅借 olive（kicker）与 navy（选中）表达。

### 3.7 按钮（Button）
- 主按钮：`background:--navy; color:#fff; --r-sm`；hover 微深（≈#152038）。
- 次按钮：`border:1px --navy; color:--navy; --r-sm`；hover 浅 navy 底。
- 文字链接型：`color:--navy` + `border-bottom:2px --orange`（如"阅读全文 →"）。
- **禁止**渐变、玻璃、外发光；按钮密度低，资讯流以阅读为主、弱化操作。

### 3.8 分页 / 加载态 / 空态（Pagination / Loading / Empty）
- 分页：serif 页码，激活态 `--orange` 下划线；"加载更多"用文字链接（orange 下划线），非彩色按钮。
- 加载：中性骨架（ink-500 低透明线条）轻微呼吸，**禁**彩色 spinner。
- 空态（精选池为空）：编辑风灰注"未进入精选 · 已回退全部结果"，`--ink-700`，配 1px `--line` 分隔；诚实标注回退逻辑。

## 四、响应式行为（Responsive）

- 断点：`≤880px` 单列；`>880px` 双栏。
- 移动端：Hero/双栏塌为单列；侧栏热点榜取消左边线、左内距归零；全局搜索框可隐藏，入口收到导航内。
- 字号用 `clamp()` 平滑收缩，保持衬线层级对比；页边距不小于 20px，留白节奏不变。
- 触控目标 ≥40px（chips/按钮）。

## 五、Anti-Slop 设计纪律（版本 B 专项 · 8 条）

1. **字体不超两套**：全站仅衬线（标题/刊期/序号）+ 无衬线（正文/UI）；禁止引入第三套装饰字体或手写体。
2. **彩色上限 3**：navy + orange + 低饱和 olive；禁用彩虹渐变、外发光、玻璃拟态、等宽终端元素（A/C 雷区）。
3. **标签不填色块**：分类 chip 一律描边 + 文字；状态用单色点（orange=进行中，ink-500=归档），禁红绿交通灯。
4. **留白节奏统一**：区块/栏距/页边距严格走 8px 栅格，宁稀勿挤；禁止把杂志风做成"密集小报"。
5. **衬线职责分明**：衬线只用于标题、刊期、序号、引文；整段长文正文用无衬线，禁衬线长文降可读性。
6. **禁假数据占位**：示例文案须为可信中文 AI 资讯（可标"示例"），原型须标"仅 UI 不含后端逻辑"；禁 lorem/乱码。
7. **分隔克制**：分隔仅用 1px 暖灰 hairline；禁多重装饰线、阴影堆叠、卡片拟物化。
8. **数据诚实**：来源筛选标"本地过滤"、智能聚合标"编辑策展+AI 综述而非语义检索"；不杜撰热度值，只用 rank 顺序。

## 六、Agent 生成引导（Agent Prompt Guide）

- 生成任何版本 B 页面时，先注入上述 CSS 变量与字体栈；所有彩色必须从令牌取，不得硬编码新色相。
- 渲染列表优先"hairline 分隔 + 大留白"，其次才是边框面板；不默认给卡片加阴影。
- 序号、刊期、来源署名必须真实可溯（来自 AIHOT 字段）；缺失字段显示"—"而非编造。
- 若需"眼前一亮"，靠编辑排印（首字下沉、栏目分隔线、刊期感日期）达成，不靠视觉特效。
