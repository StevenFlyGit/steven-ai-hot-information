## 主要改进建议（供细化阶段）

1. **A 暗黑霓虹**：光晕强度建议随屏高收敛，避免大屏"过曝"；分类标签色需保证 WCAG 对比度。
2. **B 杂志编辑**：移动端侧栏需改为折叠；衬线字体在 Windows 下回退要确认有 Source Han Serif。
3. **C 数据仪表盘**：来源"本地过滤"须在 UI 明确标注（非服务端能力）；KPI 数字需与真实 API 字段对齐（当前为占位）。
